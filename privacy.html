Airatab Privacy Policy

Effective date: June 5, 2026

Applies to: Airatab Chrome extension

Airatab is a customizable new tab extension. It is designed to be local-first. We do not sell user data, do not use user data for advertising, and do not operate a developer-controlled cloud sync service for Airatab bookmark data.

1. Information Airatab handles

Airatab may handle the following information only to provide user-facing extension features:

  • Bookmarks: browser bookmarks and bookmark folders used for bookmark search, bookmark management, import/export, and optional WebDAV bookmark sync.
  • Browsing history: browser history entries used to show history suggestions in the new tab search experience.
  • Open tabs and windows: tab titles, URLs, favicons, active tab state, and window information used for tab search, current-tab shortcut creation, switching to existing tabs, and preventing duplicate new tabs.
  • Recently closed sessions: recently closed tab information used to help users reopen recent browsing sessions.
  • Search queries: text entered by the user in Airatab search, used to open search results and, when supported, to use the browser's default search provider.
  • Local preferences and content: shortcuts, folders, wallpaper settings, layout settings, search preferences, local search history, and other extension settings saved on the user's device.
  • WebDAV configuration: the WebDAV URL, username, and password that the user enters, stored locally so Airatab can connect to the user-selected WebDAV server.

2. How Airatab uses this information

Airatab uses the information above to provide and improve the extension's single purpose: a customizable new tab workspace with shortcuts, search, bookmarks, appearance settings, and optional bookmark sync.

  • Bookmarks are used to display, search, edit, import/export, and synchronize bookmarks when the user enables WebDAV sync.
  • History and recently closed sessions are used to show relevant search suggestions in the new tab page.
  • Tabs and windows are used to search open tabs, focus existing tabs, create shortcuts from the current tab, and avoid opening duplicate tabs.
  • Search queries are used to navigate to URLs, submit searches, and show search suggestions.
  • Preferences and shortcuts are used to restore the user's new tab layout and settings.

3. Local storage

Most Airatab data is stored locally in the browser or on the user's device. This includes shortcuts, layout settings, wallpaper settings, local search history, search preferences, WebDAV configuration, and WebDAV sync baseline data.

4. WebDAV sync

WebDAV bookmark sync is optional. If the user configures and enables WebDAV sync, Airatab connects to the WebDAV server selected by the user and uploads/downloads bookmark sync data to that server. The WebDAV server may be operated by the user or by a third-party provider chosen by the user.

Airatab does not send WebDAV bookmark sync data to a developer-controlled Airatab server. Users should review the privacy and security practices of their chosen WebDAV provider.

5. Third-party services

Airatab may communicate with third-party services only for features requested by the user or needed by the selected feature:

  • User-configured WebDAV servers receive bookmark sync data and WebDAV credentials as needed to perform synchronization.
  • Search engines or suggestion providers may receive the search query text when the user performs a search or when remote search suggestions are used.
  • External image or wallpaper sources may be requested when the user uses wallpaper-related features.

Airatab does not sell personal information and does not share user data with third parties for advertising or profiling.

6. Chrome extension permissions

Airatab requests only the permissions needed for its user-facing features:

  • bookmarks: display, search, manage, import/export, and sync browser bookmarks.
  • history: show browser history suggestions in the new tab search experience.
  • sessions: show recently closed tabs so users can reopen them.
  • tabs: search open tabs, identify the current tab for shortcut creation, switch to existing tabs, and prevent duplicate new tabs.
  • search: submit searches through the browser's default search provider when selected by the user.
  • permissions: check and request optional permissions or host access only when a related feature needs it.
  • host permissions: connect to user-configured WebDAV servers and external resources needed by selected features.

7. Data retention and deletion

Locally stored extension data remains on the user's device until the user changes settings, clears browser extension data, or uninstalls the extension. WebDAV sync data remains on the user's selected WebDAV server according to that server's settings and the user's actions.

8. Limited Use statement

Airatab's use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Airatab uses Chrome API data only to provide or improve the extension's user-facing features, does not transfer the data for advertising, and does not allow humans to read the data except where necessary for security, legal compliance, or user-requested support.

9. Changes to this policy

We may update this policy when Airatab's features, permissions, or data practices change. The updated policy will be posted on this page with a new effective date.

10. Contact
